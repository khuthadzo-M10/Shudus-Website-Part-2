### Source Use

These references support the main Part 2 implementation areas:

- **Flexbox:** navigation and one-dimensional layouts.
- **CSS Grid:** service and project card layouts.
- **Media Queries:** responsive layouts for different viewport sizes.
- **Responsive design:** adapting page layout to desktop, tablet and mobile screens.
- **Typography:** Poppins and Open Sans font usage.
- **CSS layout:** spacing, alignment and responsive page structures.

> Note: The references document the technical concepts used in the website. The actual Shudus Plumbing & Construction content, organisation information, design requirements and website goals are based on the project's Part 1 documentation.
