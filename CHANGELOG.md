# CHANGELOG

All notable changes to the **Shudus Plumbing & Construction Website – Part 2** are documented in this file.

## [1.0.0] – Part 2 Styling Release

### Added
- Added the main external CSS stylesheet for the website.
- Added a professional blue, white, grey and navy colour scheme.
- Added consistent typography and visual hierarchy using Poppins and Open Sans.
- Added responsive global styling for the website.
- Added reusable container, spacing and layout styles.
- Added responsive image styling using `max-width: 100%` and `height: auto`.
- Added Flexbox layouts for navigation and other horizontal/vertical content areas.
- Added CSS Grid layouts for service cards and project cards.
- Added responsive media queries for smaller screen sizes.
- Added the `768px` responsive breakpoint for mobile/tablet layouts.
- Added sticky navigation using `position: sticky` and `top: 0`.
- Added navigation hover effects using `:hover`.
- Added styled call-to-action buttons with padding, rounded corners and transitions.
- Added hover and transition effects to interactive elements.
- Added rounded card corners using `border-radius`.
- Added card shadows using `box-shadow`.
- Added responsive About Us section layout.
- Added responsive Services section with styled service cards.
- Added Trust/Company Features section styling.
- Added responsive Projects/Gallery card and image styling.
- Added Testimonials section styling.
- Added Company Credentials section styling.
- Added Request a Quote form styling.
- Added Contact section styling and responsive layout.
- Added mobile navigation styling.
- Added consistent section headings and spacing.
- Added responsive layouts for smartphones, tablets, laptops and desktop screens.
- Added usability-focused styling for buttons, forms, navigation and content cards.

### Changed
- Improved the overall visual appearance of the website.
- Changed the layout from basic HTML presentation to a structured responsive CSS design.
- Improved navigation alignment using Flexbox.
- Improved service and project presentation using CSS Grid/Flexbox.
- Improved image behaviour so images scale proportionally without stretching.
- Improved spacing, alignment and readability across website sections.
- Improved buttons and interactive elements with clearer visual feedback.
- Improved the mobile and tablet presentation of the website.

### Responsive Design
- Added responsive rules for screens **768px and below**.
- Adjusted multi-column layouts for smaller screens.
- Improved navigation behaviour on smaller devices.
- Adjusted spacing and typography for mobile/tablet viewing.
- Ensured images remain within their containers.

### Documentation
- Added `README.md` documenting the Part 2 styling, layout techniques, responsive design and project structure.
- Added this `CHANGELOG.md` to record the development and styling changes.

### Testing
Testing should be performed on desktop, tablet and mobile screen sizes to verify:
- Navigation and links.
- Responsive layouts.
- Images.
- Buttons and hover effects.
- Forms.
- Flexbox and Grid layouts.
- Mobile navigation.
- No horizontal overflow.

Actual test results should be added after the website has been tested.
